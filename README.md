# AutoSelect Pro: Machine Learning Feature Selection Benchmarking Platform

An end-to-end automated platform to ingest tabular datasets, execute statistical and machine learning feature selection pipelines, and benchmark downstream classifier performance across accuracy, $F_1$-score, and computational efficiency.

---

## 📌 Project Overview
AutoSelect Pro bridges the gap between high-performance machine learning research and zero-code usability. It benchmarks three major paradigms of feature selection (Filter, Wrapper, and Embedded) to help researchers and developers analyze the trade-offs between feature dimensionality (model sparsity) and prediction latency.

Using a real-world tourism dataset (**Hotel Booking Demand Dataset**), the platform demonstrates how shrinking a feature space by **over 80%** (from 110+ features to the top 20) can reduce training latency by **78%** with a negligible accuracy penalty (~1%).

---

## ⚡ Key Features
*   **Zero-Click Automated Pipeline**: Auto-detects target columns, performs missing-value imputation (median/mode), filters noise, encodes categorical variables, and scales numerical values.
*   **Three Feature Selection Paradigms**:
    *   **Filter Methods**: ANOVA F-value and Scaled Chi-Square statistical tests.
    *   **Wrapper Methods**: Recursive Feature Elimination (RFE) via Logistic Regression.
    *   **Embedded Methods**: Lasso (L1 regularization) and Random Forest (Mean Decrease in Gini Impurity).
*   **Dual Downstream Classifiers**: Compares Logistic Regression (linear) and XGBoost (non-linear) models trained on both the full dataset (baseline) and each feature-selected subset.
*   **High-Fidelity Visual Suite**: Dynamically generates bar charts comparing predictive accuracy, $F_1$-score, and training speedups.
*   **Premium Glassmorphism Dashboard**: Fully responsive user interface featuring file dropzones, multi-stage loader progress sequences, and interactive metric tabs.

## 🧪 Algorithmic Details

### 1. Preprocessing Pipeline
*   **Null Imputation**: Automatically imputes continuous columns using the median and categorical columns using the mode. Special logic handles specific columns in the default hotel booking schema.
*   **Leakage Prevention**: Automatically drops target-leakage features like `reservation_status` and `reservation_status_date`.
*   **Categorical Encoding**: Utilizes one-hot encoding for categorical attributes. High-cardinality features are supported.
*   **Feature Scaling**: Scales numerical data using standard scaling (`StandardScaler`).

### 2. Feature Selection Methods
*   **ANOVA F-value**: Assesses linear relationships between numeric inputs and categorical targets using analysis of variance.
*   **Chi-Square ($χ^2$)**: Scores categorical dependencies by applying a Chi-Square test on Min-Max scaled features.
*   **Recursive Feature Elimination (RFE)**: Iteratively trains a Logistic Regression estimator and discards the least significant features.
*   **Lasso (L1 Regularization)**: Fits a Logistic Regression model with L1 penalty to select non-zero weight attributes.
*   **Random Forest Importance**: Evaluates splits across 50 decision trees, capturing non-linear feature interactions.

### 3. Downstream Classifiers
*   **Logistic Regression**: Serving as a linear classification baseline.
*   **XGBoost Classifier**: Serving as a state-of-the-art non-linear gradient-boosted tree model.

## 📊 Empirical Benchmarking Results
The benchmarking pipeline evaluated the standardized **Hotel Booking Demand Dataset** (119,390 observations, target variable: `is_canceled`). The features expanded from 31 raw columns to **110+ processed columns** after encoding. The top $K=20$ features were selected for comparative benchmarks.

| Feature Selection Method | Dimension ($K$) | Downstream Classifier | Predictive Accuracy | $F_1$ Score (Weighted) | Training Time (s) | Speedup Factor |
| :--- | :---: | :--- | :---: | :---: | :---: | :---: |
| **Baseline (All Features)** | 110+ | Logistic Regression | 81.90% | 73.32% | 3.93s | *1.0x (Ref)* |
| **Baseline (All Features)** | 110+ | XGBoost | **87.95%** | **83.38%** | 6.78s | *1.0x (Ref)* |
| **ANOVA (Filter)** | 20 | Logistic Regression | 78.57% | 65.98% | 0.59s | **6.6x** |
| **ANOVA (Filter)** | 20 | XGBoost | 83.25% | 75.67% | 0.98s | **6.9x** |
| **Chi-Square (Filter)** | 20 | Logistic Regression | 77.79% | 64.67% | 0.61s | **6.4x** |
| **Chi-Square (Filter)** | 20 | XGBoost | 82.56% | 74.84% | 0.92s | **7.3x** |
| **RFE (Wrapper)** | 20 | Logistic Regression | 76.65% | 54.94% | 0.56s | **7.0x** |
| **RFE (Wrapper)** | 20 | XGBoost | 76.76% | 55.03% | 0.97s | **7.0x** |
| **Lasso (Embedded)** | 20 | Logistic Regression | 76.37% | 54.43% | 0.45s | **8.7x** |
| **Lasso (Embedded)** | 20 | XGBoost | 76.56% | 54.57% | 1.29s | **5.3x** |
| **RF Importance (Embedded)**| 20 | Logistic Regression | 80.13% | 69.67% | 0.87s | **4.5x** |
| **RF Importance (Embedded)**| 20 | XGBoost | **86.84%** | **81.47%** | 1.44s | **4.7x** |

### Key Takeaways
1.  **Optimal Configuration**: The combination of **Random Forest Feature Importance** and **XGBoost Classifier** retains **86.84% accuracy** (only 1.11% lower than the baseline) while providing a **4.7x speedup** (execution time down from 6.78s to 1.44s).
2.  **Failure of Linear Feature Selectors**: Wrapper (RFE) and Embedded (Lasso) models using Logistic Regression performed poorly ($F_1$-score drops to ~55%). This is due to multi-collinear tabular feature structures where linear coefficient methods discard highly descriptive, correlated continuous variables in favor of sparse categoricals.
3.  **High-Efficiency Filters**: Statistical filters (ANOVA & Chi-Square) require negligible overhead to calculate. Paired with XGBoost, ANOVA achieves **83.25% accuracy** and a **6.9x speedup** in under a second, offering a great candidate for resource-constrained architectures.

For more details on results and analysis, refer to [Results_Discussion.md](file:///c:/Users/ASUS/Tourism_FeatureSelection/Results_Discussion.md).

## 🚀 Getting Started

### 📋 Prerequisites
*   Python 3.8+
*   Pip (Python Package Installer)

### 💻 Installation
1.  Clone the repository and navigate to the project directory:
    ```bash
    git clone <repository_url>
    cd Tourism_FeatureSelection
    ```
2.  Install the required dependencies:
    ```bash
    pip install -r requirements.txt
    ```

### 📥 Downloading the Benchmark Dataset
Run the download script to fetch the default hotel bookings dataset:
```bash
python src/download_dataset.py
```
This downloads and saves the `hotel_bookings.csv` dataset directly into the `data/` directory.

### 🌐 Running the Web Application
Start the Flask application backend server:
```bash
python app.py
```
After the server initializes, open your browser and navigate to:
```
http://localhost:5000
```
Simply drag and drop the downloaded `data/hotel_bookings.csv` file (or any other custom classification dataset) into the dashboard. The system will automatically run the pipelines and display the visual results.

### ⚙️ Running via Command Line Interface (CLI)
You can also run each pipeline step independently:
1.  **Preprocess the data**:
    ```bash
    python src/preprocess_data.py
    ```
2.  **Select Features**:
    ```bash
    python src/feature_selection.py
    ```
3.  **Evaluate Models**:
    ```bash
    python src/model_training.py
    ```
4.  **Generate Visual Plots**:
    ```bash
    python src/visualization.py
    ```
